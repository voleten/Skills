# Format de RESSOURCES.md

`RESSOURCES.md` est l'ensemble curaté des sources de confiance pour ce sujet. La
connaissance des leçons doit en être tirée, pas devinée de mémoire. La sagesse vient des
communautés qui y sont listées.

## Structure

```md
# Ressources — {Sujet}

## Connaissance

- [Livre : _Titre du livre_ — Auteurs](https://exemple.com)
  Texte fondateur sur la programmation et l'adaptation.
  À utiliser pour : tout ce qui touche à la périodisation, la récupération, les zones d'intensité.
- [Article : « Titre de l'article » — Auteur (Publication)](https://exemple.com)
  Revue fondée sur les données concernant les repères de volume.
  À utiliser pour : les objectifs hebdomadaires par groupe.

## Sagesse (communautés)

- [Nom du forum](https://exemple.com)
  Communauté à fort signal, modérée contre les approximations.
  À utiliser pour : critique de programme, déblocage de plateau.
- Local : cours du mardi à {lieu}
  À utiliser pour : retour d'un encadrant en temps réel.
```

## Règles

- **Haute confiance uniquement.** Privilégiez les sources primaires, les personnes
  reconnues, les travaux évalués par les pairs, et les communautés bien modérées. Si une
  ressource est du marketing déguisé en pédagogie, ne l'incluez pas.
- **Annotez chaque entrée.** Un lien nu est inutile dans trois mois. Ajoutez une ligne :
  ce qu'elle couvre et quand y recourir.
- **Groupez par Connaissance / Sagesse.** Une ressource peut n'apparaître que dans un seul
  groupe.
- **Faites remonter les manques explicitement.** Si aucune bonne ressource n'existe pour un
  domaine dont la mission a besoin, écrivez une section `## Manques` listant ce qui
  manque. C'est ce qui pilote les recherches futures.
- **Élaguez sans pitié.** Une ressource qui s'est révélée fausse, superficielle ou hors
  mission doit être retirée, pas enterrée plus bas. Mieux vaut cinq sources tranchantes
  que trente médiocres.
- **Consignez les préférences de communauté.** Si l'utilisateur a refusé de rejoindre des
  communautés, notez-le ici pour que les sessions futures cessent d'en proposer.
